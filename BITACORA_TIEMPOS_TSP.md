# Bitácora de Registro de Tiempos TSP (Time Recording Log)
## Proyecto: Catálogo Virtual · Subgrupo B05

En el proceso TSP/PSP es indispensable registrar con precisión el tiempo dedicado a cada tarea. Esto permite comparar **tiempo estimado vs. tiempo real**, equilibrar la carga del equipo y sustentar la Entrega 2 y Entrega 3.

---

### Fases Oficiales de TSP:
- **PLAN:** Planificación, estimación y elaboración de calendarios.
- **REQ:** Análisis y especificación de requisitos y criterios de aceptación.
- **DES:** Diseño de interfaz (UI), arquitectura y flujo de datos.
- **CODE:** Programación y codificación de módulos.
- **REV:** Revisiones de código por pares (Peer Code Review) e inspecciones.
- **TEST:** Pruebas unitarias, de integración y pruebas del sistema.
- **POST:** Análisis postmortem, actas de cierre y conclusiones.

### 💡 Instrucciones para cada integrante:
1. Registra tu sesión de trabajo el mismo día en que la realizas.
2. Anota el tiempo en minutos (por ejemplo, 1 hora y media = 90 minutos).
3. Si tuviste interrupciones largas (más de 10 min), descuéntalas del tiempo total.
4. Vincula la tarea a tu commit o Pull Request en GitHub para que sirva de evidencia verificable ante la tutora.
